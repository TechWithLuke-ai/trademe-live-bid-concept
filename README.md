# Trade Me Live Bid — Concept Prototype

## Overview

Trade Me Live Bid is an independent Android concept prototype exploring how auction users could continue monitoring and interacting with an active Trade Me auction while multitasking outside the main app.

The goal is to reduce the need for users to repeatedly reopen the Trade Me app just to check auction progress.

## Problem

When participating in a Trade Me auction, users may place a bid while there is still significant time remaining before the auction closes.

During this time, the user may leave the Trade Me app to watch YouTube, listen to Spotify, browse the web, message friends, or complete other tasks.

This can cause the user to lose awareness of:

- How much time remains in the auction
- The current bidding price
- Whether they are still the leading bidder
- Whether another bidder has outbid them

This may result in the user missing the opportunity to respond before the auction closes.

## Proposed Solution

Live Bid provides a compact live auction experience that allows users to continue monitoring an active auction while using other applications.

The prototype focuses on allowing the user to:

- View the remaining auction time
- View the current bidding price
- See whether they are leading or have been outbid
- Receive an outbid update
- Place another bid without navigating back through the main auction experience

## Core User Stories

1. As a Trade Me bidder, I want to see how much time remains on my auction while using another app, so that I do not lose track of when the auction is closing.

2. As a Trade Me bidder, I want to place a bid from the Live Bid interface, so that I can respond quickly while multitasking.

3. As a Trade Me bidder, I want to know when I have been outbid, so that I can decide whether to place another bid.

4. As a Trade Me bidder, I want to see the current auction price, so that I know what the auction has reached.

5. As a Trade Me bidder, I want to clearly see whether I am leading or have been outbid, so that I understand my position at a glance.

## MVP Scope

The first prototype will demonstrate one complete auction flow:

1. Open a mock auction
2. Place a bid
3. Become the leading bidder
4. Start the Live Bid experience
5. Continue monitoring the auction
6. Simulate another bidder placing a higher bid
7. Show the user as outbid
8. Allow the user to place another bid
9. Restore the user's leading status
10. End the auction with a won or lost state
